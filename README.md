# Étape 1 — Espace élève (dossier prêt à fusionner)

Ce dossier contient **tous les fichiers** de l'Étape 1, déjà placés dans la bonne arborescence.

## Comment l'utiliser

1. **Fusionne** le contenu de ce dossier dans la racine de ton dépôt `plateforme-scolaire/` :
   - les fichiers `backend/...` vont dans `backend/...`
   - les fichiers `frontend/...` vont dans `frontend/...`
2. Tous les fichiers sont **déjà modifiés** — aucune édition manuelle nécessaire.
3. Suis les **tests** décrits dans `ETAPE_1_GUIDE.md`.

## Contenu

- `backend/` : 7 fichiers Java (DTO, repository, service, contrôleur, 3 initialiseurs)
- `frontend/` : 6 fichiers TypeScript/TSX (types, endpoints, App, roles, hook, page)
- `ETAPE_1_GUIDE.md` : guide de test détaillé
